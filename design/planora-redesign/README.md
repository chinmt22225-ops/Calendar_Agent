# Planora redesign preview

Đây là prototype thiết kế độc lập, không gọi backend và không thay đổi frontend production.

- `WIREFRAMES.md`: cấu trúc và hành vi màn hình.
- `tokens.css`: design tokens light/dark.
- `mockup.html`: mockup tương tác để supervisor duyệt.
- `mockup.css`: visual system và responsive desktop.
- `mockup.js`: chuyển màn hình, theme và mở/đóng modal prototype.

Mở `mockup.html` để xem. Các nút Lịch, Trợ lý AI, Đăng nhập, Cài đặt, Thùng rác, Tạo mới và theme hoạt động trong phạm vi prototype.
